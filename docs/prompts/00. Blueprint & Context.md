# 📘 Prompt 00 — Generar Project Blueprint (Qwen Code Terminal)

## Instrucciones de Ejecución

Este prompt está diseñado para ser ejecutado por **Qwen Code** desde la terminal. El operador debe decir:

> "Ejecuta el prompt 00 para generar el Blueprint"

Qwen Code debe seguir las instrucciones abaixo y generar el documento automáticamente.

---

## Tarea para Qwen Code

Analiza TODO este proyecto y genera un documento `blueprint.md` en la carpeta `docs/03-ai-generated-content/`.

### Pasos de Ejecución

1. **Estructura de directorios:**
   - Usa `list_directory` recursivamente o `glob` para generar un árbol completo del proyecto
   - Excluye: `node_modules`, `.git`, `.venv`, `__pycache__`, `dist`, `build`, `.turbo`, `*.log`
   - Enfócate en mapear: `docs/`, `client/src/modules/`, `etl_pipeline/`
   - Compara con `client/src/config/navigation.js` — reporta discrepancias

2. **Dependencias:**
   - Lee `client/package.json` → extrae `dependencies` y `devDependencies`
   - Lee los imports de TODOS los scripts en `etl_pipeline/*.py` → lista dependencias Python de terceros
   - Detecta dependencias fantasma (instaladas pero no importadas)

3. **Arquitectura de datos:**
   - Lee TODOS los scripts en `etl_pipeline/` (01, 02, 03, 04, m05, 90, 91)
   - Documenta:
     - Capa RAW: tablas creadas por script 02
     - Capa BUSINESS: vistas creadas por script 04
     - Capa DATA MARTS: vistas creadas por script m05
     - Funciones RPC: parámetros, retorno, qué componente frontend las consume

4. **Scripts ETL:**
   - Lee `etl_pipeline/00_full_run_pipeline.py` → documenta secuencia de ejecución
   - Para cada script: qué hace, qué genera, de qué depende

5. **Frontend modular:**
   - Lee `client/src/App.jsx` → entiende el sistema de routing
   - Lista todos los módulos en `client/src/modules/` → qué archivos tiene cada uno
   - Identifica módulos placeholder (carpetas vacías)

6. **Variables de entorno:**
   - Lee `.env` (raíz y client/) → lista SOLO las keys, oculta valores con `***`
   - Detecta variables no usadas o faltantes

7. **Score de madurez:**
   - Calcula: módulos implementados vs totales, documentación al día, dependencias limpias, variables de entorno OK

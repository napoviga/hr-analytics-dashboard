4. **Archivos Huérfanos:**
   - Busca en `client/src/components/` y `client/src/modules/` archivos que nadie importa

5. **Cruce Blueprint vs Realidad:**
   - Compara `client/src/config/navigation.js` con carpetas en `client/src/modules/`

6. **Seguridad y Secrets:**
   - Escanea TODO el código buscando: API keys, tokens, passwords, connection strings literales
   - Verifica `.gitignore`: protege `.env`, `.env.*`, `__pycache__/`, `.venv/`, `node_modules/`, `dist/`
   - Revisa permisos GRANT en funciones SQL de scripts ETL

7. **UI/UX y Buenas Prácticas React:**
   - Detecta `style={{...}}` que deberían ser clases Tailwind
   - Identifica llamadas `await supabase...` dentro de `return` en vez de `useEffect`
   - Verifica `aria-label` en íconos de Lucide
   - Verifica `key` en `.map()` con IDs únicos (no índices)
